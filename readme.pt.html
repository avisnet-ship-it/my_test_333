Como funciona o laboratório

  1. As páginas têm noindex e não aparecem no Google.
  2. Nos testes de fundo, o conteúdo é a página principal original, e muda só o fundo.
    1. Eles são gerados por tools/gen_testes.py (repositório privado).
  3. As prévias revNN/ são cópias dos sites, montadas para o autor testar antes de aprovar.
    1. Como montar uma está no docs/runbook.md do privado.
  4. As prévias de antes da v4.0.0 (rev39/, links/, autor-a/, autor-b/, rev51/ e senajg-com/) saíram na SenaJG-rev.69 (15/11/2026), por decisão do autor.
    1. O histórico delas continua no Git deste repositório.
  5. Os endereços do que vem do site (imagens, ícones e programas de /assets/, páginas dos livros) estão completos, https://senajg.com.br/..., porque a raiz do lab.senajg.com.br é a do laboratório.
    1. O ajuste é do tools/lab_enderecos.py (repositório privado).
    2. Os links entre as páginas de uma prévia ficam dentro do laboratório.
  6. Densidade dos corpos celestes: padrão 2,75×; ajuste com ?d=1 (original), ?d=2.5, ?d=3... na URL.
