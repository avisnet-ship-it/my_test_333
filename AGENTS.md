# AGENTS.md — para agentes de IA

> **Se você é uma IA chegando a este repositório:** ele é o laboratório, onde ficam as prévias que o autor aprova antes de qualquer coisa ir aos sites. Tudo o que importa (as regras de trabalho com o autor, a ordem de leitura, como montar uma prévia, como publicar) está no repositório privado do projeto, `avisnet-ship-it/privado`. **Comece pelo `AGENTS.md` do privado** (é preciso ter acesso a ele, dado pelo autor).

- Uma prévia nova é uma pasta nova (`revNN`, `revNNb`, …), com `noindex`, uma linha no `index.html` e no `README.md`, e o commit `SenaJG-rev.N+test.M` (`docs/runbook.md` do privado, seção 3).
- Este repositório é público: nada interno entra aqui.
